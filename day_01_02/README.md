* ⏱️ 10 min | Create a Pull Request

## Goals
By the end of the day, participants should:
* Understand the overall structure and components of the project, evaluation criteria and final project expectations.
* Analyze the given business scenario and identify its data-related challenges.
* Successfully install all required development tools.
* Create and configure necessary user accounts on GitHub and Azure.
* Set up a new GitHub repository for the project.
* Practice essential Git commands for daily project collaboration.

## Theory
Thoretical topics to be covered.

### Project Overview
* **Objective**: Understand the high-level project structure and how it's organized and managed through GitHub.
* **Topics**:
   * Project structure and components (scripts, data, documentation).
   * Repository layout and folder conventions.
   * Importance of version control in data engineering.
   * How the GitHub repository supports collaboration and tracking.

### Scenario Overview
* **Objective**: Analyze and validate the real-world scenario that the project will address.
* **Topics**:
   * Business context of the scenario.
   * Expected data sources and outputs.
   * Challenges and objectives of the use case.
   * Project goals aligned with the scenario.

### Install Tools
* **Objective**: Ensure participants have a complete local setup with all required development tools. Undestand the role of each tool in the data engineering workflow.
* **Topics**:   
   * Git for version control.
   * Python as the main programming language.
   * PostgreSQL as the relational database.
   * VS Code as the development environment.
   * pgAdmin for database management and visualization.

### Create Accounts
* **Objective**: Set up essential cloud and version control accounts for project execution and deployment.
* **Topics**:
   * Importance of GitHub for code collaboration and CI/CD.
   * Use of Azure for cloud-based data engineering tools and infrastructure.

### Project Initialization
* **Objective**: Set up the initial environment and repository to begin collaborative development.
* **Topics**:
   * Repository creation process and settings (visibility, license, README).
   * Virtual environments for Python projects.
   * Core Git concepts: init, add, commit, push, pull, branch.
   * Pull Requests for collaboration and review.

## Practice
Practical topics to be covered.

### Project Overview
* **Objective**: Understand the high-level project structure and how it's organized and managed through GitHub.
* **Topics**:
   * Explore a sample project repository.
   * Navigate key folders (e.g., `src/`, `ducuments/`).
   * Identify where to place new code, documentation, or configs.

### Scenario Overview
* **Objective**: Analyze and validate the real-world scenario that the project will address.
* **Topics**:
   * Discuss the scenario in pairs or as a group.
   * Write down the main business questions and expected deliverables.
   * Confirm assumptions and clarify scope with a facilitator.

### Install Tools
* **Objective**: Ensure participants have a complete local setup with all required development tools. Undestand the role of each tool in the data engineering workflow.
* **Topics**:   
   * Step-by-step installation of each tool.
   * Verify successful installation (e.g., `git --version`, `python --version`).
   * Open VS Code and connect to PostgreSQL via pgAdmin.

### Create Accounts
* **Objective**: Set up essential cloud and version control accounts for project execution and deployment.
* **Topics**:
   * Register and set up a GitHub account.
   * Create a new Azure account and complete verification.
   * Log in and navigate the dashboards of both platforms.

### Project Initialization
* **Objective**: Set up the initial environment and repository to begin collaborative development.
* **Topics**:
   * Create a GitHub repo from scratch or from a template.
   * Set up a Python virtual environment and install packages.
   * Execute key Git commands in the terminal (clone, add, commit, push).
   * Create a feature branch and open a Pull Request.

## Individual work
Tasks for participant's own project.

* Create a template for the project.
* Elaborate the project scenario.
* Install on own machine all required tools.
* Create GitHub account.
* Create Azure account.
* Create a new GitHub repository.
* Clone the repository locally and add a `README.md` file.
* Create a Python virtual environment and install the dependencies.
* Push changes (`README.md`, `.gitignore`, and `requirements.txt`) to the GitHub repository.
* Create a new branch called `setup`.
* Make an update to the `README.md`, commit the change, and push it.
* Open a Pull Request from the `setup` branch to `main`.
